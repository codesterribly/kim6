KIM6 (Kde Image Menu 6)

KIM6 is a service menu for KDE used for example by Dolphin and other users of KIO. KIM6 allows you to perform actions on your images (and videos) from your desktop or file manager without having to use other applications. This service menu can be considered as a frontend of ImageMagick (and FFmpeg).

Menus

  • Compress and resize

    This menu allows you to compress and resize images. Compression can significantly reduce the size of images in exchange for some loss of detail. Resizing changes the size of images but keeps scale. Each action defines a maximum size of the resulting image.

    So if your image is 2000x1000 (landscape orientation) and you resize it to 500x500, your resulting image will be 500x250 (so the limit will be applied to horizontal length of the image).

    If your image is 1000x2000 (portrait orientation) and you resize it to 500x500, your resulting image will be 250x500 (so the limit will be applied to vertical height of the image).

    Web export combines resizing and encoding, always creates a separate derived image, and never replaces its source. JPEG compression is available from a JPEG-only submenu. Outputs use safe staging and collision handling.

  • Convert and rotate

    This menu converts images to JPEG, PNG, GIF, BMP5, TIFF, PDF, WebP, or AVIF; it also provides custom format selection, EXIF auto-orientation, fixed/custom rotation, and horizontal/vertical flips.

  • Treatment and publication

    Rename selected images interactively, number a batch from a custom base, or rename from EXIF dates using supported date formats.

    Resize images for email and open a supported mail client with successfully prepared attachments.

    Metadata stripping removes the configured EXIF, GPS, XMP, and IPTC metadata while retaining image pixels, color profile, orientation behavior, permissions, and the original modification timestamp.

    Create an HTML gallery, a photo collage, a multi-page TIFF, an animated GIF, a PDF album, or a print-layout PDF.

    Basic treatment effects and obsolete Sony multiburst processing are excluded from the unified menus.

    You can also display a license, the names of authors and this help.

  • Video Compress and resize

    Transcodes video using either libx264 or libx265 to HD (1280x720) or FullHD (1920x1080) in three qualities (CFR values 17, 23 and 29 — only 17 should more or less preserve the amount of detail). Audio is copied and container (like MKV) is either preserved or converted to MP4.

Usage

KIM6 is used via the file manager context menu. Select one or more image or video files, right-click, and choose the desired action from the KIM6 submenu.

Most actions will prompt for confirmation before overwriting existing files. Pressing Enter will usually select the default option, which is to create new files rather than overwrite existing ones.

Some behavior can be customized using environment variables. These variables can be set in the environment where your file manager is launched.

All installed Dolphin processing entries launch the unified kim_all dispatcher and pass local selections as individual arguments. The historical kim_* source scripts are references and are not installed as active commands.

Configuration

Set KIM_POLICY=create to create new outputs or KIM_POLICY=overwrite to authorize replacement for actions that support it. Unset or other values show the action's create/overwrite choice. Web export always creates derived images and never overwrites a source.

KIM_NAME_AFFIX_POSITION=prefix|suffix controls the placement of web, compressed, resized, and stripped tags. Its KConfig key is NAME_AFFIX_POSITION; the default is suffix and the environment takes precedence.

Web-export defaults use KIM_WEB_FORMAT=jpg|webp|avif|keep and KIM_WEB_QUALITY=1..100. The quality setting supplies the dialog default. Format support depends on ImageMagick encoders.

File behavior

Rotation and metadata stripping preserve modification timestamps; rename/move operations preserve file metadata. Compression, conversion, resize, and flip/flop create changed content with fresh modification timestamps. Other output files are derived artifacts. Successful mail-resize attachments remain in ${XDG_DATA_HOME:-~/.local/share}/kim6/email-attachments after mail-client handoff so asynchronous clients can read them; remove the prepared files when finished.

Menus are restricted to local files. Remote URLs are not processed. See installation and dependency notes for upgrade, uninstall, and runtime details.
