02 REUSABLE PHOTO WORKFLOWS

Your photo workflow, one recipe.

KIMng now has a dedicated KIMng - Recipes menu in Dolphin. Instead of repeating several operations on the same images, combine them into a reusable recipe and run the entire workflow from the right-click menu.

Choose and run a recipe

The Recipes submenu contains saved Root shortcuts and commands to open the recipe chooser or editor. Review the planned operations, filenames, destination, and readiness before running. The built-in Web Export recipe creates JPEG derivatives at quality 95 without overwriting selected originals.

Manage your recipe library

Open Recipe editor… to browse Built-In, Root, named folders, and Unfiled recipes. Search by recipe name, description, or folder. Duplicate a protected built-in before customizing it.

Each recipe contains ordered processing operations, optional disabled steps, output naming rules, and a destination. The editor displays a planned-output preview. Use its import/export controls to move individual recipes or recipe bundles between installations. Only recipes explicitly assigned to Root appear as direct Dolphin shortcuts.

When running a recipe, select it and inspect readiness, planned filenames, and destinations for every selected image. Output name collisions may be resolved during planning, but a collision after approval blocks publication rather than silently changing the approved filename. Recipes always create derivatives.

See the complete Recipes reference for processing steps, library organization, and JSON details.

1

Select your photos

Select one or more images in Dolphin, right-click, and open KIMng - Recipes.

2

Choose a recipe

Choose Run a recipe… to select built-in Web Export or browse your saved recipes. Recipes assigned to Root can also appear directly in Dolphin.

3

Preview and run

Review the selected files, processing steps, planned outputs, and configured destination. Choose a folder only when the recipe requests one; run when every file is ready.

↗

Web Export, ready to use

Inside Run a recipe…, the built-in Web Export auto-orients and fits images within 1600 × 1600 pixels without upscaling, applies sRGB, saves JPEG at quality 95, and removes all metadata. Results go into a Web subfolder beside each original.

vacation.jpg → Web/vacation_web.jpg
⚙

Create your own recipes

Open Recipe editor… to create, edit, or duplicate recipes. Combine steps such as resizing, format conversion, metadata removal, and output renaming. Enable or disable individual steps, and organize saved recipes into folders in the selector. Assign a recipe to Root to add a direct Dolphin shortcut.

Use output filename patterns such as {filename}_recipe and preview the resulting filenames before processing.

Know what will happen before running. Run a Recipe checks the selected images and previews the planned results. Files requiring attention are identified before processing. For example, a Photoshop PSD that needs an output conversion format can offer Fix recipe… to open the existing recipe editor and correct the problem.

Your originals stay untouched. Recipes always create separate output files, never overwrite the selected source images, and protect existing output filenames from collisions. Read the complete Recipes reference ↗.

Resize, crop, rotate, and flip images

Resize: Select a preset, enter exact dimensions, resize by percentage, or use advanced ImageMagick geometry. Fit presets retain image proportions. The Allow enlargement option is off by default, so smaller images are not enlarged unless you enable it. Percentage resizing can explicitly enlarge an image. Choose resampling separately where offered, and inspect the planned dimensions before applying changes.

Crop: Open the Crop interface, select an aspect ratio, exact pixel dimensions, or a manual crop area. Position the selection on the image preview and continue to Review Changes to inspect the planned output.

Rotate and flip: Rotate by a custom angle or apply EXIF auto-orientation, choosing separate copies or authorized replacement where supported. Horizontal and vertical Flip always open Review Changes and create separate images. Flip never overwrites the originals, regardless of the configured output policy.

Convert or compress?

Convert changes the image format. Compress adjusts encoding settings for a supported format. Choose Recommended, Maximum, or Custom where available.

JPEG, WebP, and AVIF support lossy encoding choices. PNG compression remains lossless. A format listed in a menu may still be unavailable without the required encoder. Before applying, inspect warnings about transparency, color precision, embedded profiles, and metadata.

Resize, convert, and crop

Resize presets preserve aspect ratio. Conversion and compression offer format-specific choices. Cropping lets you define the crop area, inspect the resulting image, and review output before applying changes.

06 INFORMATION INSIDE YOUR FILES

Control metadata and dates.

Photos can contain location, camera, author, and capture-date information. KIMng gives you targeted ways to work with it.

Browse and compare image metadata

Select one or more images in Dolphin and choose Organize Metadata → View metadata…. The read-only Metadata Browser displays image previews, a human-readable overview, and searchable technical tags. You can inspect tag names, values, groups, and source representations without modifying the selected images.

A field may have different values in embedded XMP, an XMP sidecar, IPTC-IIM, or EXIF. The default display priority is embedded XMP, XMP sidecar, IPTC-IIM, then EXIF. Alternate representations remain available for inspection; a preferred value does not erase or reconcile conflicting values elsewhere.

To compare two files, choose the Left and Right images in Metadata Browser and choose Compare images. Compare overview fields or all fields to inspect matching values, differences, and alternate representations. Browsing and comparison do not modify image files or associated sidecars.

Plan metadata changes without writing them

Choose Organize Metadata → Edit metadata… to open the Metadata Editor. The current Editor is a read-only change planner, not an enabled metadata writer.

Inspect individual image fields or prepare batch proposals using Leave unchanged, Fill empty, Replace, or Clear. Mixed values, missing values, empty fields, and conflicting representations require explicit choices. Entering a blank value does not mean Clear.

When several representations exist, identify the intended metadata source and language. The Editor retains drafts while navigating images and provides a review of proposed changes and warnings. That review does not write image metadata, modify originals, or create XMP sidecars.

Use KIMng's separate existing GPS operations when you need to perform a supported location change.

Remove GPS and AI metadata

Select Location/GPS › Remove GPS metadata… to remove recognized GPS coordinate fields while retaining unrelated metadata.

Use Location/GPS to inspect location metadata, modify photo GPS coordinates, or approximate precise positions. Edit GPS on images… offers another image, map selection, manual coordinates, and GPX tracks as location sources.

Select Organize Metadata › Strip metadata to review available metadata-removal options, including recognized AI-generation information.

trip.jpg→trip_gps.jpg

If there is no matching GPS metadata, KIMng reports the file unchanged and creates no copy.

Copyright and capture times

Add creator and copyright information, adjust or set a photo capture date, set capture dates from filesystem dates, or set file modification dates from photo capture dates. Use Organize Metadata in Dolphin to choose the appropriate action.

Time shifting is a fixed adjustment, not a timezone conversion. EXIF timestamps and filesystem modification times are different things.

!

Privacy note: KIMng removes recognized GPS coordinates and AI-generation metadata, but some information may remain. These tools cannot guarantee complete removal of location or AI-related information.

Organize image files and dates

Check actual formats before correcting filename extensions. Use Set dates to inspect and change supported timestamps. The Organize Metadata submenu also provides renaming, overlays, rights information, and unified metadata stripping.

Choose the appropriate GPS operation

View GPS metadata… opens KIMng's existing GPS viewer.

Edit GPS on images… can use manually entered coordinates, map selection, a reference image, or a GPX track where supported.

Reduce exact GPS location… replaces precise coordinates with an approximate position. Remove GPS metadata… removes recognized coordinate fields. These are distinct operations.

For modifying actions, inspect the chosen location, affected images, and planned changes before applying. Metadata Browser and Editor provide View on map access to a compact map for the selected GPS fields; field-level Edit GPS or Add GPS actions are available where supported. Viewing does not apply a change. The Metadata Editor retains pending proposals when opening the map.

Remember that captions, other metadata, and visible landmarks may still reveal a location after coordinate metadata is removed.

Inspect and modify GPS information

Modify GPS can use a reference image, manually entered coordinates, a map, or a GPX track where supported. Reducing coordinate precision replaces precise coordinates with an approximate location. Removing GPS metadata is a separate action. Inspect the planned changes before applying them.

07 MAKE SOMETHING NEW

Create and publish images.

Turn your photos into galleries, collages, albums, animations, or slideshows. KIMng saves the results separately, leaving your original images untouched.

▤Gallery PublishingOffline image galleries and photo stories, with optional sections and multiple pages.
▦CollageSeveral pictures in one image.
▧PDF album & printMulti-page albums or print layouts.
▥Multi-page TIFFCombine images into one TIFF.
◉Animated GIF/APNGAnimation from selected images.
▶MP4 slideshowChoose timing, dimensions, frame rate, background and destination in one dialog. Images play in natural filename order.

Collages include grid, mosaic, hero, filmstrip and scattered layouts with operation-specific canvas, spacing, background, frame and shadow controls. Gallery Publishing has its own chooser, story editor, styles, and offline website output. Printable PDF contact sheets complement albums and print layouts. Slideshows are silent and straightforward: fixed time per image, without titles, transitions, pan, or zoom effects. Successful PDF and other publication workflows identify the saved result; when notices are available, Details (N) expands them for inspection.

Choose the right publication format

Collage: Arrange images using the available grid, mosaic, hero, filmstrip, or scattered layouts. Inspect the composition, canvas size, background, spacing, and optional framing before creating the output.

Slideshow preview: The interactive slideshow settings provide a selected-slide preview and a playback timestamp readout before rendering the silent MP4.

Contact sheet: Choose paper size, orientation, grid arrangement, image fitting, labels, and resolution for a printable PDF.

Convert PDF pages to images: Render the pages of a selected PDF into separate image files. Choose an output format and review the planned filenames and destinations before applying changes.

Extract embedded PDF images: Extract image resources from a PDF without rendering whole pages. Review the planned outputs before extraction. Both PDF input actions use Poppler utilities, default to placing results beside each source PDF, and leave the original documents untouched.

PDF album and print layout: Arrange selected images into ordered PDF pages using the available album or print presets.

Animated image: Choose GIF or APNG, frame delay, looping, and destination. Encoder availability and animation limits determine which output is supported. See the format reference.

Multi-page TIFF: Combine selected images into one TIFF document.

Video slideshow: Create a silent MP4 from images, choosing timing, dimensions, frame rate, background, and destination. This is a straightforward slideshow without transitions, titles, or animated camera movement.

These publication tools create derivatives rather than replacing the selected source images. Inspect the planned results and destinations before publication.

Build collages and publication files

The Create/Publish submenu includes collages, PDF albums, contact sheets, galleries, animations, slideshows, and other outputs. The Collage dialog provides layout, image order, canvas, spacing, and background controls along with a composition preview.

GALLERY PUBLISHING

Build a gallery or photo story.

Select images in Dolphin, right-click, and choose KIMng - Create/Publish → Create a gallery…. Choose Image gallery to open the classic gallery creator, or Photo story to open the three-panel story editor described below. These are different workflows.

Image gallery

The classic image gallery creator lets you order images, edit captions, choose columns, select the Clean Light or Dark Portfolio theme, and choose Standard (up to 1920 px) or High (up to 3840 px) image resolution. Inspect the gallery preview before publishing. This workflow does not offer the Photo story editor's sections, multiple-page structure, or ZIP Review Changes workflow.

Photo story

Arrange your story

The editor has three panels: Story order on the left, the image and story canvas in the middle, and Gallery settings on the right. Change the image order, select an image to edit its information, or use Add heading and Add text to add narrative passages. Preview the website before publishing.

Choose a gallery type, style, and arrangement

Choose Travelogue, Photo essay, Illustrated story, or Simple gallery. The independent Visual style choices are Classic, Modern, Dramatic, Light, and Dark. Image arrangement offers One image, Up to two images, Adaptive, Justified (proportional rows), and Masonry (staggered columns). You can also choose whether to show captions and filenames.

Organize a trip or longer story into sections

Under Website structure, choose Single page to make one scrolling site with section links, or Multiple pages to make a home page and separate pages for sections. Choose Sections… to add named sections, such as places visited or chapters of a story. Give each section a title, an optional description, and an optional cover image. Check images in Images in this publication to assign them to the selected section. When your story has headings or paragraphs, the Story text control lets you assign those existing passages too. Unassigned material stays in the publication; removing a section does not delete its content.

Preview, review, and publish

Choose Gallery folder (recommended) or ZIP archive under Output format, then inspect the destination. Use Preview in browser to view the result in a browser. Review Changes shows planned pages, images, viewer files, destinations, and blocked items before anything is written. KIMng creates a new publication without overwriting your original images or replacing an existing gallery; conflicts require a new review. Generated gallery images do not carry embedded source metadata.

Open the resulting index.html locally to browse the website, including its full-screen image viewer. The site is designed for offline use. If you want to host it online, upload the published folder or extracted ZIP yourself; KIMng does not upload sites.

For the command and safety details, see the Gallery Publishing command reference.

08 VIDEO WORKFLOWS

Video tools, directly in Dolphin.

Right-click a supported video and open Actions. KIMng provides three video conversion submenus, organized by codec, and a separate Video Utilities submenu. Settings/About remains accessible alongside them.

Choose a video operation

Use KIMng - Convert Video: AV1, H.264, or H.265 to create a re-encoded video. Use Video Utilities for extracting or publishing parts of an existing video.

Convert video: choose resolution and quality

Each codec submenu contains six MP4 presets: 1080p or 720p, each with High quality, Balanced, or Smallest file settings. The quality choices represent different encoding parameters, not guaranteed output sizes. Actual file size depends on the source video and available encoder.

H.264 is generally the best starting point for broad playback compatibility. H.265 offers more efficient compression in many situations but requires compatible playback software or hardware. AV1 is a newer codec that can achieve high compression efficiency, although encoding speed and playback support depend on the system.

The screenshot below shows the AV1 presets. The H.264 and H.265 menus offer the same resolution-and-quality combinations, with their respective codecs.

Video Utilities

These operations are separate from video transcoding:

  • Extract audio… saves supported audio from the video.
  • Extract frame at timestamp… captures an image from a chosen point in the video.
  • Extract automatic thumbnail creates a representative still image.
  • Remove audio (copy video) creates a silent video without re-encoding the compatible video stream.
  • Create video contact sheet… combines representative frames into a single overview image.
  • Create animated GIF from video… turns a selected video segment into an animation.

Output safety. Video utilities produce separate outputs. Video conversion supports the applicable create-new and explicitly authorized overwrite policies. KIMng checks encoder and container compatibility, and a requested format may be unavailable if the installed FFmpeg build lacks the necessary encoder. Read the format compatibility reference ↗.

09 BEFORE YOU CLICK

Your originals stay protected.

KIMng protects your original files by default. When an action could replace an original, you must explicitly approve the change. Nothing is silently overwritten.

+

Create new

KIMng creates a separate file and leaves your original unchanged. When you are asked to choose, this is the default selection.

↻

Overwrite protection

Replacing an original requires deliberately choosing Overwrite and approving a separate confirmation warning. You can cancel without changing the file.

!

Rotate and flip safely

Rotation and automatic EXIF orientation can offer authorized replacement. Horizontal and vertical Flip always create separate reviewed images and never overwrite the originals.

Output policy depends on the operation. Some interactive Review Changes dialogs, including Resize, Compress, and Convert video, provide their own Create and Overwrite choices. A saved output-policy preference does not automatically determine every dialog's available choices. Flip and other create-only operations never offer replacement of selected originals. Where replacement is supported, it requires explicit approval.

Choose your defaults in Settings. In Dolphin, right-click a supported image or video and open Actions → KIMng - Settings/About → Settings. Choose whether supported operations should create separate files automatically or ask how to proceed. Save your preferences to use them for subsequent operations.

Actions that create separate files. Web export, email preparation, galleries, albums, slideshows, and video frame, audio, and GIF tools leave your originals untouched. Video transcoding can also replace an original, but only after explicit confirmation.

Existing filenames and processing failures. KIMng avoids silently overwriting existing results. Where supported, it adds a number to resolve filename conflicts. It checks generated output before publishing it, and successfully completed results remain available if a later item in the batch fails. See file-handling and configuration details.

Understand Review Changes

Before applying a supported operation, inspect the original and proposed result, exact output filename, destination directory, per-file status, and warnings. Resolve blocked items rather than assuming they will be skipped or automatically renamed.

For derivative operations, the default destination is beside each source, including batches selected from different source directories. Where offered, Change destination… selects a shared output directory. Confirm that the displayed planned paths reflect your choice.

Once a publication plan has been approved, a new destination collision or changed source must not silently alter the approved result. The operation should block the affected output rather than overwrite or rename it without another review.

Cancel abandons the pending operation. Previously completed publications in a batch may remain. The Metadata Editor's review is different: it previews draft proposals but does not yet execute metadata writes.

Review changes before publication

Inspect the proposed results, filenames, directories, and per-file status. Resolve blocked items before proceeding. Different operations have different review controls, but KIMng protects originals through their applicable output and overwrite rules.

Configure settings and help

Settings includes output policy, image quality, location units, creator and rights information, and map loading. Output Filenames controls generated filename labels. Settings/About also provides the license, application information, and HTML User Guide.

10 WHEN SOMETHING GOES WRONG

Troubleshooting common problems.

If a menu is missing or an action fails, these common checks can help you identify and resolve the problem.

My KIMng menus are missing.

Restart Dolphin and verify the service menus were installed to a directory that Dolphin recognizes. A KDE Frameworks/KIO 6.29 regression affected submenu display; the fix is available in later Frameworks releases. Do not flatten KIMng submenus as a workaround.

Installation and troubleshooting guide ↗

A format or encoder is unavailable.

ImageMagick and FFmpeg support varies with the installed build and its delegates. KIMng reports unavailable codecs rather than silently switching to a different output format. Animated APNG conversion needs FFmpeg; Resize and Web Export deliberately refuse animated APNG to avoid losing frames. Check the format reference for inspection commands.

Supported formats and encoders ↗

An action failed partway through a batch.

Read the final error report, confirm the source is readable and the destination is writable, and check that the requested encoder is available. Successfully completed outputs remain in place. Test uncertain inputs using copies.

Command reference and troubleshooting ↗

Where are my files, and what if a filename already exists?

Many Create new actions save a derivative beside the input and add a number when the requested filename is occupied. Other actions prompt for a destination, use a configured output folder, or place email attachments in a persistent directory. Read the action's result dialog for the exact location.
