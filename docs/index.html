01 FIRST STEPS

Start with a single photo.

No new application to learn. KIM6 adds actions to the context menu you already use in Dolphin.

1

Select

Choose one or more local photos or videos in Dolphin.

2

Right-click

Open a KIM6 submenu and choose the task you want.

3

Save

For actions that offer a choice, select Create new to keep the original file.

i

New to KIM6? Choose Create new files (recommended; originals untouched). Create mode publishes separate files, including rotated or flipped copies. Replacing an original requires choosing Overwrite and approving a second confirmation. How file handling works.

02 EVERYDAY EDITS

Your most useful photo actions.

These are actual menu examples. Output names assume the default suffix naming convention and Create new mode when that choice is offered.

↗SIZE

Resize a photo

Fit a photo inside a maximum width and height without cropping its proportions. This preset can enlarge smaller images; percentage resize supports 1–1000%.

MENU PATH

Resize/Rotate › Resize to 1600 × 1600
lake.jpg→lake_resized.jpg
≋QUALITY

Compress a JPEG

Create a JPEG using a chosen quality setting. Lower quality may reduce file size, but can lose detail. Custom compression also offers progressive/baseline scans and Huffman optimization.

MENU PATH

Convert/Compress › Compress Recommended
lake.jpg→lake_compressed.jpg
⇄FORMAT

Convert an image

Convert between supported formats, including optional JPEG XL, JPEG 2000, AVIF and HEIC/HEIF delegates. JPEG is lossy and cannot preserve transparent PNG areas; codec support is checked before publication.

MENU PATH

Convert/Compress › Convert to JPEG
garden.png→garden.jpg
▦BATCH

Process several files

Select several photos and apply the same action. Finished outputs remain available if a later item fails.

MENU PATH

3 selected photos→3 resized files

If an output filename is already taken, KIM6 creates a numbered name. Prefix naming can be configured instead of the default suffix format. Naming and command options ↗

03 READY TO SEND

Share without changing the source.

Prepare smaller files for the web or email while leaving the selected photographs intact.

↗

Web export

Save a resized JPEG, WebP, or AVIF derivative to a chosen folder. Web export never replaces the selected original. Animated APNG inputs are refused to prevent a still-frame export; ordinary PNG remains supported.

By default, usable embedded color profiles are converted to sRGB. You can instead choose to preserve a compatible profile.

✉

Email preparation

Prepare resized attachments or attach selected files at full size, depending on the action. Prepared copies remain in a persistent attachment folder because mail applications may read them later.

Review attachments before sending and clean up prepared copies when you no longer need them.

04 INFORMATION INSIDE YOUR FILES

Control metadata and dates.

Photos can contain location, camera, author, and capture-date information. KIM6 gives you targeted ways to work with it.

Remove GPS coordinates

Select Organize/Metadata › Strip GPS Metadata… to target recognized GPS fields without removing all other metadata.

trip.jpg→trip_gps.jpg

If there is no matching GPS metadata, KIM6 reports the file unchanged and creates no copy.

Copyright and capture times

Add creator and copyright information, shift recorded camera times, or synchronize embedded timestamps and filesystem modification times in either direction. A fixed time shift is not a timezone conversion.

Time shifting is a fixed adjustment, not a timezone conversion. EXIF timestamps and filesystem modification times are different things.

!

GPS-only removal does not guarantee complete location anonymization. Other metadata or visible scene details may still reveal a location. Metadata removal also cannot guarantee complete removal of signed provenance records.

07 BEFORE YOU CLICK

Know what happens to the original.

Not every action has the same output policy. These are the distinctions that matter most.

+

Create new

Where the action offers this choice, the result gets a separate filename and your original remains unchanged.

↻

Authorized overwrite

Select Overwrite originals (confirmation required), then confirm the separate warning identifying originals, renamed files, or derived outputs and the selected-file count. Cancel is safe.

!

Transform images

Rotation, EXIF auto-orientation, flip and flop support both output modes. Create saves transformed copies and preserves originals. Overwrite replaces originals only after explicit confirmation and output validation.

KIM_POLICY=create selects separate outputs where supported; KIM_POLICY=prompt displays the output-policy dialog. Create mode numbers colliding output names, while authorized publication validates outputs and checks unsafe symlinks, hardlinks and source aliases. Completed batch outputs survive later failures. Web exports, email copies, galleries, albums, slideshows and video frame/audio/GIF utilities leave selected sources intact. Video transcoding may replace originals only after explicit overwrite confirmation. See file-handling and configuration details ↗.

08 WHEN SOMETHING GOES WRONG

Find a fix.

Check these common causes first. No need to test a failing action by overwriting a valuable photograph.

My KIM6 menus are missing.

Restart Dolphin and verify the service menus were installed to a directory that Dolphin recognizes. A KDE Frameworks/KIO 6.29 regression affected submenu display; the fix is available in later Frameworks releases. Do not flatten KIM6 submenus as a workaround.

Installation and troubleshooting guide ↗

A format or encoder is unavailable.

ImageMagick and FFmpeg support varies with the installed build and its delegates. KIM6 reports unavailable codecs rather than silently switching to a different output format. Animated APNG conversion needs FFmpeg; Resize and Web Export deliberately refuse animated APNG to avoid losing frames. Check the format reference for inspection commands.

Supported formats and encoders ↗

An action failed partway through a batch.

Read the final error report, confirm the source is readable and the destination is writable, and check that the requested encoder is available. Successfully completed outputs remain in place. Test uncertain inputs using copies.

Command reference and troubleshooting ↗

Where are my files, and what if a filename already exists?

Many Create new actions save a derivative beside the input and add a number when the requested filename is occupied. Other actions prompt for a destination, use a configured output folder, or place email attachments in a persistent directory. Read the action's result dialog for the exact location.
