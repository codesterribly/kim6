01 FIRST STEPS

Start with a single photo.

No new application to learn. KIM6 adds actions to the context menu you already use in Dolphin.

1

Select

Choose one or more local photos or videos in Dolphin.

2

Right-click

Open a KIM6 submenu and choose the task you want.

3

Save

For actions that offer a choice, select Create new to keep the original file.

i

KIM6 is designed to protect your originals. When an action offers a choice, Create new files (originals untouched) is selected by default. Replacing an original requires choosing Overwrite and confirming a separate warning. How file handling works.

02 REUSABLE PHOTO WORKFLOWS

Your photo workflow, one recipe.

KIM6 now has a dedicated KIM6 - Recipes menu in Dolphin. Instead of repeating several operations on the same images, combine them into a reusable recipe and run the entire workflow from the right-click menu.

Choose and run a recipe

The Recipes submenu contains saved Root shortcuts and commands to open the recipe chooser or editor. Review the planned operations, filenames, destination, and readiness before running. The built-in Web Export recipe creates JPEG derivatives at quality 95 without overwriting selected originals.

1

Select your photos

Select one or more images in Dolphin, right-click, and open KIM6 - Recipes.

2

Choose a recipe

Choose Choose saved recipe… to select built-in Web Export or browse your saved recipes. Recipes assigned to Root can also appear directly in Dolphin.

3

Preview and run

Review the selected files, processing steps, planned outputs, and configured destination. Choose a folder only when the recipe requests one; run when every file is ready.

↗

Web Export, ready to use

Inside Choose saved recipe…, the built-in Web Export auto-orients and fits images within 1600 × 1600 pixels without upscaling, applies sRGB, saves JPEG at quality 95, and removes all metadata. Results go into a Web subfolder beside each original.

vacation.jpg → Web/vacation_web.jpg
⚙

Create your own recipes

Open Recipe editor… to create, edit, or duplicate recipes. Combine steps such as resizing, format conversion, metadata removal, and output renaming. Enable or disable individual steps, and organize saved recipes into folders in the selector. Assign a recipe to Root to add a direct Dolphin shortcut.

Use output filename patterns such as {filename}_recipe and preview the resulting filenames before processing.

Know what will happen before running. Run a Recipe checks the selected images and previews the planned results. Files requiring attention are identified before processing. For example, a Photoshop PSD that needs an output conversion format can offer Fix Recipe… to open the existing recipe editor and correct the problem.

Your originals stay untouched. Recipes always create separate output files, never overwrite the selected source images, and protect existing output filenames from collisions. Read the complete Recipes reference ↗.

Prepare smaller files for the web or email while leaving the selected images intact. ✉

Email preparation

Prepare photos for email at their original size or resize them to make sharing easier. KIM6 prepares the attachments for your email application without changing your original images.

Export images for sharing

The Web Export submenu provides twelve format-and-size presets. Its shipped JPEG, WebP and AVIF quality defaults are 95, but user settings can change them (the screenshot shows one configured value). Review Web Export displays output dimensions, format, quality, filenames, readiness, and destination choices before processing. These direct presets are distinct from the built-in Web Export recipe.

06 INFORMATION INSIDE YOUR FILES

Control metadata and dates.

Photos can contain location, camera, author, and capture-date information. KIM6 gives you targeted ways to work with it.

Remove GPS and AI metadata

Select Location/GPS › Remove GPS metadata… to remove recognized GPS coordinate fields while retaining unrelated metadata.

Use Location/GPS to inspect location metadata, modify photo GPS coordinates, or approximate precise positions. Modify GPS on images… offers another image, map selection, manual coordinates, and GPX tracks as location sources.

Select Organize/Metadata › Strip metadata to review available metadata-removal options, including recognized AI-generation information.

trip.jpg→trip_gps.jpg

If there is no matching GPS metadata, KIM6 reports the file unchanged and creates no copy.

Copyright and capture times

Add creator and copyright information, adjust or set a photo capture date, set capture dates from filesystem dates, or set file modification dates from photo capture dates. Use Organize/Metadata in Dolphin to choose the appropriate action.

Time shifting is a fixed adjustment, not a timezone conversion. EXIF timestamps and filesystem modification times are different things.

!

Privacy note: KIM6 removes recognized GPS coordinates and AI-generation metadata, but some information may remain. These tools cannot guarantee complete removal of location or AI-related information.

Organize image files and dates

Check actual formats before correcting filename extensions. Use Set dates to inspect and change supported timestamps. The Organize/Metadata submenu also provides renaming, overlays, rights information, and unified metadata stripping.

Inspect and modify GPS information

Modify GPS can use a reference image, manually entered coordinates, a map, or a GPX track where supported. Reducing coordinate precision replaces precise coordinates with an approximate location. Removing GPS metadata is a separate action. Inspect the planned changes before applying them.

08 VIDEO WORKFLOWS

Video tools, directly in Dolphin.

Right-click a supported video and open Actions. KIM6 provides three video conversion submenus, organized by codec, and a separate Video Utilities submenu. Settings/About remains accessible alongside them.

Choose a video operation

Use KIM6 - Convert Video: AV1, H.264, or H.265 to create a re-encoded video. Use Video Utilities for extracting or publishing parts of an existing video.

Convert video: choose resolution and quality

Each codec submenu contains six MP4 presets: 1080p or 720p, each with High quality, Balanced, or Smallest file settings. The quality choices represent different encoding parameters, not guaranteed output sizes. Actual file size depends on the source video and available encoder.

H.264 is generally the best starting point for broad playback compatibility. H.265 offers more efficient compression in many situations but requires compatible playback software or hardware. AV1 is a newer codec that can achieve high compression efficiency, although encoding speed and playback support depend on the system.

The screenshot below shows the AV1 presets. The H.264 and H.265 menus offer the same resolution-and-quality combinations, with their respective codecs.

Video Utilities

These operations are separate from video transcoding:

  • Extract audio… saves supported audio from the video.
  • Extract frame at timestamp… captures an image from a chosen point in the video.
  • Extract automatic thumbnail creates a representative still image.
  • Remove audio (copy video) creates a silent video without re-encoding the compatible video stream.
  • Create video contact sheet… combines representative frames into a single overview image.
  • Create animated GIF from video… turns a selected video segment into an animation.

Output safety. Video utilities produce separate outputs. Video conversion supports the applicable create-new and explicitly authorized overwrite policies. KIM6 checks encoder and container compatibility, and a requested format may be unavailable if the installed FFmpeg build lacks the necessary encoder. Read the format compatibility reference ↗.

09 BEFORE YOU CLICK

Your originals stay protected.

KIM6 protects your original files by default. When an action could replace an original, you must explicitly approve the change. Nothing is silently overwritten.

+

Create new

KIM6 creates a separate file and leaves your original unchanged. When you are asked to choose, this is the default selection.

↻

Overwrite protection

Replacing an original requires deliberately choosing Overwrite and approving a separate confirmation warning. You can cancel without changing the file.

!

Rotate and flip safely

Rotate or flip images as separate copies, or choose to replace the originals after explicit confirmation. Automatic EXIF rotation has the same protection.

Choose your defaults in Settings. In Dolphin, right-click a supported image or video and open Actions → KIM6 - Settings/About → Settings. Choose whether supported operations should create separate files automatically or ask how to proceed. Save your preferences to use them for subsequent operations.

Actions that create separate files. Web export, email preparation, galleries, albums, slideshows, and video frame, audio, and GIF tools leave your originals untouched. Video transcoding can also replace an original, but only after explicit confirmation.

Existing filenames and processing failures. KIM6 avoids silently overwriting existing results. Where supported, it adds a number to resolve filename conflicts. It checks generated output before publishing it, and successfully completed results remain available if a later item in the batch fails. See file-handling and configuration details.

Review changes before publication

Inspect the proposed results, filenames, directories, and per-file status. Resolve blocked items before proceeding. Different operations have different review controls, but KIM6 protects originals through their applicable output and overwrite rules.

Configure settings and help

Settings includes output policy, image quality, location units, creator and rights information, and map loading. Output Filenames controls generated filename labels. Settings/About also provides the license, application information, and HTML User Guide.

10 WHEN SOMETHING GOES WRONG

Troubleshooting common problems.

If a menu is missing or an action fails, these common checks can help you identify and resolve the problem.

My KIM6 menus are missing.

Restart Dolphin and verify the service menus were installed to a directory that Dolphin recognizes. A KDE Frameworks/KIO 6.29 regression affected submenu display; the fix is available in later Frameworks releases. Do not flatten KIM6 submenus as a workaround.

Installation and troubleshooting guide ↗

A format or encoder is unavailable.

ImageMagick and FFmpeg support varies with the installed build and its delegates. KIM6 reports unavailable codecs rather than silently switching to a different output format. Animated APNG conversion needs FFmpeg; Resize and Web Export deliberately refuse animated APNG to avoid losing frames. Check the format reference for inspection commands.

Supported formats and encoders ↗

An action failed partway through a batch.

Read the final error report, confirm the source is readable and the destination is writable, and check that the requested encoder is available. Successfully completed outputs remain in place. Test uncertain inputs using copies.

Command reference and troubleshooting ↗

Where are my files, and what if a filename already exists?

Many Create new actions save a derivative beside the input and add a number when the requested filename is occupied. Other actions prompt for a destination, use a configured output folder, or place email attachments in a persistent directory. Read the action's result dialog for the exact location.
