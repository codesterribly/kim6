Start here

KIM6 is designed for KDE Plasma 6 and Dolphin. Install it from a project checkout, then restart Dolphin. Select one or more local files and look for the KIM6 menus in the right-click menu. For a first try, select photo.jpg, choose Resize (1600x1600 pixels), then choose Create new if asked; photo_resized.jpg appears beside the original.

To install from a checkout, you need Git and intltool-merge. At run time, ImageMagick handles most photo work, ExifTool handles metadata, and FFmpeg with ffprobe handles video. KDialog and qdbus provide dialogs and progress. Optional formats and encoders depend on your system; see formats and codecs.

git clone https://github.com/KIM-6/kim6.git
cd kim6
./install.sh

Install KIM6 Follow five everyday examples

Keep an eye on the output choice. Many actions let you create a new file or replace a selected file. Choose Create new when you want to keep the selected original. The choice may not appear if your output preference is already set to overwrite. Web export, resized email copies, video frame/audio/GIF tools, mute, and slideshows make separate results. Full-size email mode attaches selected originals without changing them. Video transcoding can replace a selected video when you authorize it.

Working with photos

Resize

Choose a maximum width and height, or enter a percentage. KIM6 keeps the photo's proportions. A 1600 × 1600 setting means the image fits within that box; it does not force a square crop.

Compress a JPEG

Choose a JPEG quality preset or enter a custom value. Lower quality may reduce detail. Progressive JPEG and coding-table optimization are available in the custom workflow; optimization does not guarantee a smaller file.

Convert a format

Use the format choices for JPEG, PNG, GIF, BMP5, TIFF, PDF, WebP, AVIF, HEIC/HEIF, JPEG XL, and JPEG 2000. Custom format is limited to encoders available on your computer. Some conversions lose detail, transparency, layers, or animation.

Rotate or flip

Rotate by a preset or custom angle, apply the camera's orientation setting, or flip horizontally and vertically. These actions can create a copy or replace the selected image when authorized.

Preparing images to share

Web export makes a resized JPEG, WebP, or AVIF copy in a folder you choose. It always creates a separate file, even when the general preference is set to replace files. By default, web export converts color using an sRGB profile when a usable source profile is available. You can choose to preserve the source profile instead.

Email preparation can attach the selected originals at full size, or prepare smaller copies for common attachment sizes. It does not replace the selected files. KIM6 keeps prepared copies available after handing them to a mail program; if no supported mail program is available, it offers a persistent folder for the copies.

See color and output preferences.

Removing private information

Remove GPS coordinates targets recognized location-coordinate fields and leaves unrelated metadata in place. It cannot guarantee that every location clue is gone. Strip metadata removes much more, including ordinary camera and descriptive details. Review the choice before continuing.

Removing recognized AI-generation fields is best-effort. Signed C2PA Content Credentials and other unknown records may remain. Removing metadata does not make an image impossible to identify as AI-generated.

Metadata actions can create copies or replace the selected files, depending on the action and your output choice. They do not intentionally recompress image pixels. See the safety guide for the differences.

Working with photo dates

Rename photos from their EXIF capture date, adjust camera timestamps, or synchronize the capture date and the file's modification time. The dialogs identify which date is being changed. A camera timestamp often has no time-zone information; KIM6 does not assume that it means UTC.

Filesystem dates and dates stored inside a photo are separate. Changing one does not necessarily change the other. Some metadata-only changes preserve the file's modification time, while image transformations normally receive a fresh one.

Working with video

Video presets make H.264 or H.265 copies at 720p or 1080p. Optional AV1 presets are available when a supported encoder is installed. The selected codec and container are not silently replaced when unavailable or incompatible.

You can also extract a frame or audio track, make a contact sheet or GIF from a video segment, and remove audio while copying the video stream without re-encoding it. These utilities create separate outputs. Video-to-GIF is different from making an animation from still images.

Albums, galleries, and slideshows

Make an HTML gallery, collage, PDF album, print-layout PDF, multi-page TIFF, or animated GIF from selected images. A simple MP4 slideshow displays selected photographs in natural filename order for the requested time. It has no music, transitions, titles, or editing timeline.

The HTML gallery contains its own pages and image copies in a new output folder. For file outputs, Create new mode avoids occupied names. Where an action supports replacement, the choice may be set by your output preference instead of a prompt.

Finding your results

Most image copies are placed beside the selected files. In a resize or JPEG-compression batch, outputs go in the folder of the first selected file. These actions add tags such as _resized and _compressed before the extension. Actions with collision-numbered outputs add a number when a name is taken. Web export uses the folder you select and adds _web by default. Other actions may ask where to save the result.

Filename tags can be placed before or after the name using the name-affix setting. The exact behavior for each action is in the menu inventory.

What happens to selected files?

For actions that offer both choices, Create new keeps the selected original and makes a separate result. Overwrite existing replaces only the destination that the action is authorized to update, after a successful operation. The dialog may be skipped when an output preference is configured.

Renaming changes file names or locations. Date synchronization may change either the file's modification date or embedded photo dates. Web export, resized email copies, video frame/audio/GIF utilities, and slideshows do not replace selected source media. Full-size email mode attaches the selected files without changing them. Video transcoding can replace a selected video after authorization. Batch work can finish some files and report others as failed; completed results remain.

Read Safe handling of originals before choosing an overwrite preference.

Troubleshooting

I installed KIM6, but I cannot see its menus.

Restart Dolphin and confirm the five service-menu files are under the active KDE service-menu folder. KDE Frameworks/KIO 6.29 has a known upstream issue affecting submenu display. KIM6 keeps its submenus; do not remove the submenu setting. See the installation guide.

An action says a format or encoder is unavailable.

Support depends on the image tools, video encoders, and profiles installed on your system. KIM6 reports unavailable formats rather than silently substituting another one. Check formats and codecs.

Where should I look for more help?

Start with the Getting Started guide. For installation or removal, use the installation guide. Include the action name and a short description of what happened when reporting a problem. Do not send private photographs unless you have permission.
