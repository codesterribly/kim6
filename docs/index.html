KIM6

Quick image and video operations, right where your files are.

KIM6 adds a focused set of processing tools to Dolphin’s context menus. Select files, choose an operation, and let KIM6 prepare a validated result without opening a full editing application.

Capabilities Get started Safe output Help

What you can do

KIM6 is for quick, repeatable jobs. It complements photo and video applications such as digiKam, darktable, GIMP and Kdenlive; it is not a replacement for a catalog, RAW development or editing timeline.

Prepare images

Compress JPEGs, resize by dimensions or percentage, convert supported formats, rotate, flip and create web-ready or email copies.

Manage photo details

Rename and sort by capture date, synchronize camera and file dates, edit creator/copyright fields, shift capture times, or remove selected metadata.

Make collections

Create HTML galleries, collages, PDF albums and print layouts, joined TIFFs, and animated GIFs from still images.

Work with video

Use H.264, H.265 and optional AV1 presets; extract frames and audio; mute video without re-encoding; make contact sheets and GIFs; create a simple MP4 slideshow.

Get started

KIM6 targets KDE Plasma 6 and Dolphin’s KIO service-menu system. The installer puts one dispatcher and its required resources in place, then installs five service menus. Menu entries call the installed kim_all path directly.

Install for your user

git clone https://github.com/KIM-6/kim6.git
cd kim6
./install.sh

For optional system-wide or custom-prefix installation, see the installation guide. The runtime needs Bash, ImageMagick 7, ExifTool, FFmpeg/ffprobe and KDE’s KDialog/D-Bus tools. Optional codecs and ImageMagick delegates determine which formats are available.

Use from Dolphin or the command line

Select one or more local files, right-click, and choose an operation from the KIM6 submenu. Most actions offer interactive settings; menu presets pass explicit arguments. In the examples, kim_all stands for the installed .../kim6/bin/kim_all path, or ./src/bin/kim_all from a source checkout:

kim_all resize --size 1600x1600 -- photo.jpg
kim_all webexport --size 800x800 --quality 75 -- photo.jpg
kim_all video --size hd720 --crf 23 --codec libx264 --container mp4 -- clip.mkv

Commands require their documented inputs and tools. See the CLI reference and format guide.

Careful with originals

Actions that support replacement stage and validate output before publishing. Create mode avoids occupied names and numbers collisions. Derived-only workflows—including web export, email preparation, video utilities and slideshows—never replace selected sources, even if overwrite policy is configured.

Metadata, color and timestamp behavior varies by action. Some operations intentionally update a selected file after authorization; others preserve filesystem times or create derivatives. Review the safety guide and configuration reference before setting policy.

Compatibility and project status

KIM6 is designed for KDE Plasma 6 Dolphin. The development system’s KDE Frameworks/KIO 6.29 has an upstream submenu display regression. KIM6 retains its intended submenus and does not claim live Dolphin acceptance on that affected system. Automated menu and installed-resource integration checks remain available; graphical acceptance can be performed on a compatible KDE installation.

The processing feature set is frozen while the project completes its documentation and release review. The canonical test suite is run with python3 -B tests/run.py; optional codec tests may skip when a local encoder is unavailable.
