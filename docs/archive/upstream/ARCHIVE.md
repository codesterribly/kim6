# Historical documentation archive

These files are preserved for project history. Current users should start with the repository [README](../../../README.md), [installation guide](../../../INSTALL.md), [developer guide](../../../DEVELOPMENT.md), and the current references linked from them. The archived upstream commands describe the older multi-script KIM project and are not KIM6 installation instructions.

## Original upstream documents

The `upstream/` files were copied byte-for-byte from the `upstream/master` Git ref at commit `764c9fe` (the original upstream documentation available in this repository history):

- `README.md` — upstream project overview and historical usage.
- `INSTALL.md` — upstream installation guide for the separate legacy scripts.
- `DEVELOPMENT.md` — upstream contributor/development notes.
- `index.html` — upstream web manual.
- `work.css` — stylesheet for the upstream manual.

## Pre-overhaul KIM6 snapshot

The `pre-overhaul/` files were copied byte-for-byte from the KIM6 parent commit `1278daf`, immediately before the Package 11 documentation rewrite:

- `README.md` — the then-current KIM6 overview.
- `INSTALL.md` — the then-current, mixed-generation installation instructions.
- `DEVELOPMENT.md` — the then-current KIM6 development guide.
- `index.html` and `work.css` — the then-current web manual and stylesheet.

The pre-overhaul documents included KIM6 edits and are explicitly identified as snapshots, not untouched upstream originals. The unchanged bytes of `DEVELOPMENT.md` and `work.css` happen to match the upstream copies; their provenance is still recorded separately in the two directories.

The archive intentionally excludes LICENSE files, historical source code, generated assets and vendored trees. The project license and original authorship/credit notices remain in their existing files.
